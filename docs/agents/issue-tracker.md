# Issue tracker conventions

Issues and pull requests live in `luizomf/omxterm`. Contributors follow the standard [fork-and-PR workflow](../../CONTRIBUTING.md); maintainers manage labels, triage, and releases.

## Common GitHub CLI commands

```sh
gh issue list --repo luizomf/omxterm --state open
gh issue view <number> --repo luizomf/omxterm --comments
gh pr list --repo luizomf/omxterm --state open
gh pr view <number> --repo luizomf/omxterm --comments
```

See [triage labels](triage-labels.md) for the repository's status labels and [domain references](domain.md) for specification and ADR links.
